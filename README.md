# Achoo Ledger

A one-tap sneeze tracker for the phone. Each tap logs a timestamped sneeze, a second button marks when an antihistamine was taken, and a 14-day chart shows the pattern. Works offline as an installable app, keeps data on the device, syncs every entry to a private Google Sheet, and saves a daily CSV backup.

No data is stored in this repository. It contains only the app.
